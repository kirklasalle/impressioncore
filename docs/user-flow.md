## User Onboarding

* **Sign Up:**
    1. User navigates to the sign-up page.
    2. User enters a username and password.
    3. The app validates the input.
    4. The app creates a new user account in the database.
    5. The app redirects the user to the login page.
* **Log In:**
    1. User navigates to the login page.
    2. User enters their username and password.
    3. The app validates the input against the database.
    4. If the credentials are valid, the app authenticates the user and redirects them to the main application.
    5. If the credentials are not valid, the app displays an error message.

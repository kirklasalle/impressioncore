# ImpressionCore Visualization Components

This document describes the visualization capabilities of ImpressionCore and the required dependencies.

## Required Dependencies

The advanced visualizations in ImpressionCore require several Python packages. These can be installed using the provided requirements file:

pip install -r requirements-visualization.txt

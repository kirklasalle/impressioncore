# DevOps

* Hosting: To be determined. Frontend will likely be self-hosted, and the backend will likely be hosted with Google Cloud.
* CI/CD: Yes, the app should use continuous integration and deployment with GitHub Actions.
* Monitoring: Yes, monitoring tools such as Sentry should be used for error tracking and performance monitoring.
* Scaling: No, the app will not be designed for horizontal scaling.

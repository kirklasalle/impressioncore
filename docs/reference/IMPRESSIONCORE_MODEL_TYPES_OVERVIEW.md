## Purpose

Define the ImpressionCore model types and their intended distribution, roles, and audiences.

## Series at a glance

### Impressioncore‑B3 (Series 3) — Open Source

- Role: Flagship open‑source line targeting consumer hardware accessibility.
- Baseline: 39M parameter “constitutional foundation” optimized for GTX 1050 Ti (4GB).
- Focus: Conversation quality, multimodal readiness, protection‑first design.
- Distribution: Open‑source code and community checkpoints.

### Impressioncore‑AVT — Freeware

- Role: Freeware distribution for broad user access with curated builds.
- Focus: Practical usability and simple install; governed by freeware license.
- Distribution: Prebuilt binaries/packages; limited modification rights.

### Impressioncore‑IDC — Commercial

- Role: Commercial offering oriented to deployments with compliance/security needs.
- Focus: Enterprise features, support/SLAs, management tooling and integrations.
- Distribution: Licensed access, managed updates, deployment guidance.

### Impressioncore‑IU1 — Commercial

- Role: Specialized commercial variant for targeted use‑cases/integrations.
- Focus: Domain‑specific optimizations and partner ecosystem features.
- Distribution: Licensed access, with optional customization services.

### Impressioncore‑IS1 — Freeware

- Role: Starter/freeware bundle for education and community experimentation.
- Focus: Ease of use and learning path; limited feature set compared to commercial lines.
- Distribution: Freeware packages with update channel.

## Hardware & deployment fit (high level)

- B3: Must run on GTX 1050 Ti class hardware; open‑source reference for broader ecosystem.
- AVT/IS1: Freeware builds optimized for simple installation on consumer PCs.
- IDC/IU1: Commercial options with deployment tooling for workstations/servers as required.

## Constitutional alignment

- B3 remains the constitutional baseline guiding all variants (efficiency, protection‑first, consumer accessibility).
- All distributions comply with the Permanent Architectural Framework and Fifth Law.

## Core Components

### ModalEngine

The central processing engine that orchestrates all components and manages the processing pipeline.

#### ModalEngine Initialization

```python
from src.pipeline.main import ModalEngine

# Initialize with default settings
engine = ModalEngine()

# Initialize with custom configuration
engine = ModalEngine(
    config_path="path/to/config.json",
    use_brainsim=False
)
```

#### ModalEngine Properties

| Property | Type | Description |
|----------|------|-------------|
| model | ModelManager | Access to the underlying model |
| knowledge_store | UniversalKnowledgeStore | Access to the knowledge graph |
| generator | ResponseGenerator | Access to the response generation system |
| config_manager | ConfigManager | Access to configuration settings |

#### ModalEngine Methods

##### `process_input(text: str) -> str`

Process a text input and return a response.

**Parameters**:

- `text` (str): The input text to process

**Returns**:

- str: The generated response

**Example**:

```python
response = engine.process_input("Tell me about Mars")
print(response)  # Prints information about Mars
```

##### `add_pre_processing_hook(func: Callable[[str], str]) -> None`

Add a hook that is applied to input text before processing.

**Parameters**:

- `func` (`Callable[[str], str]`): A function that takes a string and returns a string

**Example**:

```python
def lowercase_hook(text):
    return text.lower()

engine.add_pre_processing_hook(lowercase_hook)
```

##### `add_post_processing_hook(func: Callable[[str], str]) -> None`

Add a hook that is applied to response text after generation.

**Parameters**:

- `func` (`Callable[[str], str]`): A function that takes a string and returns a string

**Example**:

```python
def add_disclaimer(text):
    return text + "\\n\\nThis response was generated by AI."

engine.add_post_processing_hook(add_disclaimer)
```

##### `shutdown() -> None`

Gracefully shut down the engine and release resources.

**Example**:

```python
engine.shutdown()
```

### UniversalKnowledgeStore

A graph-based knowledge representation system with support for inheritance, relations, and persistence.

#### UniversalKnowledgeStore Initialization

```python
from src.knowledge.uks import UniversalKnowledgeStore

# Initialize with default settings
uks = UniversalKnowledgeStore()

# Initialize with custom settings
uks = UniversalKnowledgeStore(
    persistence_path="path/to/storage.json",
    max_nodes=10000
)
```

#### UniversalKnowledgeStore Methods

##### `add_node(name: str, attributes: Dict = None, parent: Union[str, 'KnowledgeNode'] = None) -> 'KnowledgeNode'`

Add a node to the knowledge graph.

**Parameters**:

- `name` (str): Name of the node
- `attributes` (Dict, optional): Dictionary of attributes for the node
- `parent` (`Union[str, KnowledgeNode]`, optional): Parent node or name of parent node. Note: `KnowledgeNode` refers to the class within the UKS module.

**Returns**:

- `KnowledgeNode`: The created node. Note: `KnowledgeNode` refers to the class within the UKS module.

**Example**:

```python
animal = uks.add_node("Animal", {"can_move": True})
mammal = uks.add_node("Mammal", {"has_fur": True}, parent=animal)
dog = uks.add_node("Dog", {"barks": True}, parent=mammal)
```

##### `query_nodes(attribute_name: str, attribute_value: Any) -> List['KnowledgeNode']`

Query nodes based on attribute values.

**Parameters**:

- `attribute_name` (str): Name of the attribute to query
- `attribute_value` (Any): Value to match

**Returns**:

- `List[KnowledgeNode]`: List of matching nodes. Note: `KnowledgeNode` refers to the class within the UKS module.

**Example**:

```python
# Find all nodes that can bark
barking_nodes = uks.query_nodes("barks", True)
```

##### `add_fact(node_name: str, attribute_name: str, attribute_value: Any) -> bool`

Add a fact (attribute-value pair) to a node.

**Parameters**:

- `node_name` (str): Name of the target node
- `attribute_name` (str): Name of the attribute
- `attribute_value` (Any): Value to set

**Returns**:

- bool: Success status

**Example**:

```python
# Add that dogs are loyal
uks.add_fact("Dog", "loyal", True)
```

### MultiModalProcessor

Processes multiple modalities of input (text, image, audio).

#### MultiModalProcessor Initialization

```python
from src.pipeline.multimodal import MultiModalProcessor

processor = MultiModalProcessor()
processor.initialize()
```

#### MultiModalProcessor Methods

##### `process_text(text: str) -> np.ndarray`

Process text input into an embedding.

**Parameters**:

- `text` (str): Input text

**Returns**:

- np.ndarray: Text embedding

**Example**:

```python
text_embedding = processor.process_text("Hello world")
```

##### `process_image(image: np.ndarray) -> np.ndarray`

Process image input into an embedding.

**Parameters**:

- `image` (np.ndarray): Input image (H,W,C)

**Returns**:

- np.ndarray: Image embedding

**Example**:

```python
import cv2
image = cv2.imread("image.jpg")
image_embedding = processor.process_image(image)
```

##### `fuse_modalities(*embeddings) -> np.ndarray`

Fuse multiple embeddings into a unified representation.

**Parameters**:

- `*embeddings`: Variable number of embeddings

**Returns**:

- np.ndarray: Fused embedding

**Example**:

```python
text_emb = processor.process_text("A sunset")
image_emb = processor.process_image(sunset_image)
fused_emb = processor.fuse_modalities(text_emb, image_emb)
```

### DynamicMemoryOptimizer

Manages dynamic offloading and reloading of model modules to/from GPU memory to enable training and inference of large models on VRAM-constrained hardware.

#### DynamicMemoryOptimizer Location

`src.core.memory.dynamic_manager.DynamicMemoryOptimizer`

#### DynamicMemoryOptimizer Initialization

```python
from src.core.memory.dynamic_manager import DynamicMemoryOptimizer
import torch
import torch.nn as nn

# Assuming 'model' is an instance of torch.nn.Module
# and 'offload_candidates_keys' is a list of string keys for modules to consider for offloading.
# If offload_candidates_keys is None, it will consider all named modules.
# Example: offload_candidates_keys = ['layer1', 'encoder.block.0']
model = nn.Sequential(nn.Linear(10,10), nn.ReLU(), nn.Linear(10,5)) # Example model
# Ensure model is on GPU if CUDA is available
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model.to(device)

optimizer = DynamicMemoryOptimizer(model, offload_candidates_keys=None, verbose=True)
```

#### DynamicMemoryOptimizer Methods

##### `adapt_to_available_memory(required_memory_mb: float = 100.0) -> None`

Adapts model memory usage by offloading modules if available GPU memory is below `required_memory_mb`. This method should be called when operating on a CUDA-enabled GPU.

**Parameters**:

- `required_memory_mb` (float): The minimum GPU memory (in MB) that should be free. Modules will be offloaded until this much memory is available or no more candidates can be offloaded. Default: 100.0 MB.

**Example**:

```python
if torch.cuda.is_available():
    # Ensure at least 200MB of GPU memory is free
    optimizer.adapt_to_available_memory(required_memory_mb=200.0)
else:
    print("CUDA not available, skipping adapt_to_available_memory.")
```

##### `offload_module(module_key: str) -> None`

Moves a specific module from GPU to CPU memory. This method should be called when operating on a CUDA-enabled GPU.

**Parameters**:

- `module_key` (str): The key (name) of the module to offload.

**Example**:

```python
# Offload the module associated with the first linear layer (assuming its key is '0')
# Note: Keys depend on how the model is structured (e.g., nn.Sequential names them numerically)
# For a model like: self.layer1 = nn.Linear(10,10), the key would be 'layer1'
if torch.cuda.is_available() and '0' in optimizer.module_sizes:
    optimizer.offload_module('0')
elif not torch.cuda.is_available():
    print("CUDA not available, skipping offload_module.")
```

##### `reload_module(module_key: str) -> None`

Moves a specific module from CPU back to GPU memory. This method should be called when operating on a CUDA-enabled GPU.

**Parameters**:

- `module_key` (str): The key (name) of the module to reload.

**Example**:

```python
# Reload the module associated with '0'
if torch.cuda.is_available() and '0' in optimizer.offloaded_modules:
    optimizer.reload_module('0')
elif not torch.cuda.is_available():
    print("CUDA not available, skipping reload_module.")
```

##### `get_module_size_mb(module: torch.nn.Module) -> float`

Estimates the memory size of a given module in megabytes.

**Parameters**:

- `module` (torch.nn.Module): The module for which to estimate the size.

**Returns**:

- float: Estimated size of the module in MB.

**Example**:

```python
# Assuming model has a module named '0' (e.g., from nn.Sequential)
if '0' in dict(model.named_modules()):
    layer_module = dict(model.named_modules())['0']
    size_mb = optimizer.get_module_size_mb(layer_module)
    print(f"Module '0' size: {size_mb:.2f} MB")
```

## Utility Components

### ConfigManager

Manages configuration settings for the system.

#### ConfigManager Initialization

```python
from src.core.config import ConfigManager

# Default config path
config = ConfigManager()

# Custom config path
config = ConfigManager(config_path="path/to/config.json")
```

#### ConfigManager Methods

##### `get(section: str, key: str, default: Any = None) -> Any`

Get a configuration value.

**Parameters**:

- `section` (str): Configuration section
- `key` (str): Configuration key
- `default` (Any, optional): Default value if key doesn't exist

**Returns**:

- Any: Configuration value or default

**Example**:

```python
model_name = config.get("models", "default_model", "gpt-4")
```

##### `set(section: str, key: str, value: Any) -> None`

Set a configuration value.

**Parameters**:

- `section` (str): Configuration section
- `key` (str): Configuration key
- `value` (Any): Value to set

**Example**:

```python
config.set("models", "default_model", "claude-3-sonnet")
```

### ModelManager

Manages model loading, inference, and saving with dual shadow architecture support.

#### ModelManager Initialization

```python
from src.models.dual_shadow import ModelManager
from src.core.config import ConfigManager

config = ConfigManager()
model_manager = ModelManager(config=config)
```

#### ModelManager Methods

##### `load_models(primary_path, shadow_path=None) -> bool`

Load the primary and optional shadow models.

**Parameters**:

- `primary_path` (str): Path to primary model
- `shadow_path` (str, optional): Path to shadow model

**Returns**:

- bool: Success status

**Example**:

```python
model_manager.load_models(
    primary_path="models/impressioncore-7b",
    shadow_path="models/impressioncore-7b-experimental"
)
```

##### `generate(prompt, max_tokens=100, temperature=0.7, use_shadow=False) -> str`

Generate text from a prompt.

**Parameters**:

- `prompt` (str): Input prompt
- `max_tokens` (int): Maximum tokens to generate
- `temperature` (float): Sampling temperature
- `use_shadow` (bool): Whether to use shadow model

**Returns**:

- str: Generated text

**Example**:

```python
response = model_manager.generate(
    prompt="Tell me about Mars",
    max_tokens=200,
    temperature=0.8
)
```

##### `embed(text) -> np.ndarray`

Generate embeddings for text.

**Parameters**:

- `text` (str): Input text

**Returns**:

- np.ndarray: Text embedding

**Example**:

```python
embedding = model_manager.embed("Hello world")
```

## Script Interfaces

### prepare_training_data.py

Processes raw data (text, images) into training examples.

#### prepare_training_data.py Usage

```bash
python scripts/prepare_training_data.py [--data-dir DATA_DIR] [--output-dir OUTPUT_DIR] [--clean]
```

#### prepare_training_data.py Arguments

| Argument | Description | Default |
|----------|-------------|---------|
| --data-dir | Directory containing raw data | data/raw |
| --output-dir | Directory to save processed data | data/processed |
| --clean | Clean and recreate sample data | False |

#### prepare_training_data.py Example

```bash
# Process data with default paths
python scripts/prepare_training_data.py

# Process data with custom paths
python scripts/prepare_training_data.py --data-dir custom/data --output-dir custom/output

# Clean and recreate sample data
python scripts/prepare_training_data.py --clean
```

### train_model.py

Trains an ImpressionCore model on processed data.

#### train_model.py Usage

```bash
python scripts/train_model.py [--model-dir MODEL_DIR] [--data-dir DATA_DIR] [--model-name MODEL_NAME] [--epochs EPOCHS] [--batch-size BATCH_SIZE] [--learning-rate LEARNING_RATE] [--seed SEED] [--fp16]
```

#### train_model.py Arguments

| Argument | Description | Default |
|----------|-------------|---------|
| --model-dir | Directory to save trained model | models |
| --data-dir | Directory containing processed training data | data/processed |
| --model-name | Model name to train (impressioncore-1b, impressioncore-3b, impressioncore-7b) | impressioncore-1b |
| --epochs | Number of training epochs | 10 |
| --batch-size | Batch size for training | 32 |
| --learning-rate | Learning rate | 2e-5 |
| --seed | Random seed | 42 |
| --fp16 | Use mixed precision training | False |

#### train_model.py Example

```bash
# Train with default settings
python scripts/train_model.py

# Train with custom settings
python scripts/train_model.py --model-name impressioncore-7b --epochs 20 --batch-size 16 --learning-rate 1e-5 --fp16
```

### evaluate_model.py

Evaluates a trained model on test cases.

#### evaluate_model.py Usage

```bash
python scripts/evaluate_model.py [--model-dir MODEL_DIR] [--test-file TEST_FILE] [--output-file OUTPUT_FILE] [--similarity-threshold SIMILARITY_THRESHOLD]
```

#### evaluate_model.py Arguments

| Argument | Description | Default |
|----------|-------------|---------|
| --model-dir | Directory containing model | models |
| --test-file | Path to test cases JSON file | data/evaluation/test_cases.json |
| --output-file | Path to output evaluation results | "" (console only) |
| --similarity-threshold | Similarity threshold (0-1) | 0.7 |

#### evaluate_model.py Example

```bash
# Evaluate with default settings
python scripts/evaluate_model.py

# Evaluate with custom settings
python scripts/evaluate_model.py --model-dir models/custom --test-file custom_tests.json --output-file results.json --similarity-threshold 0.8
```

### benchmark_tokenizer.py Script

Benchmarks the speed and memory usage of different tokenizers.

#### benchmark_tokenizer.py Location

`src/tools/benchmark_tokenizer.py`

#### benchmark_tokenizer.py Usage

```bash
python src/tools/benchmark_tokenizer.py --tokenizer_name_or_path TOKENIZER --sample_text_file FILE_PATH [--num_iterations N] [--batch_size BS] [--device DEVICE] [--no_decode]
```

#### benchmark_tokenizer.py Arguments

| Argument                 | Description                                                                 | Default      |
|--------------------------|-----------------------------------------------------------------------------|--------------|
| --tokenizer_name_or_path | Name or path of the Hugging Face tokenizer (e.g., 'bert-base-uncased').     | (Required)   |
| --sample_text_file       | Path to a .txt file containing sample texts, one per line.                  | (Required)   |
| --num_iterations         | Number of times to run the benchmark for averaging.                         | 3            |
| --batch_size             | Batch size for tokenization and decoding.                                   | 32           |
| --device                 | Device to simulate for (tokenizers are mainly CPU bound, 'cuda' checks VRAM). | "cpu"        |
| --no_decode              | Skip the decoding benchmark.                                                | False        |

#### benchmark_tokenizer.py Example

```bash
# Benchmark 'bert-base-uncased' tokenizer with a sample text file
python src/tools/benchmark_tokenizer.py --tokenizer_name_or_path bert-base-uncased --sample_text_file d:\\Projects\\impressioncore\\data\\sample_benchmark_text.txt --num_iterations 5 --batch_size 64

# Benchmark a local tokenizer and skip decoding
# python src/tools/benchmark_tokenizer.py --tokenizer_name_or_path ./my_local_tokenizer --sample_text_file ./data/my_texts.txt --no_decode
```

#### benchmark_tokenizer.py Output

The script prints benchmarking results to the console, including:

- Tokenizer loaded
- Dataset loaded
- Time taken for tokenization
- Samples processed per second
- Peak memory usage during tokenization (if `memory_profiler` is installed and supported)

## Error Handling

Most API functions follow a consistent error handling pattern:

1. Return `None` or `False` to indicate failure
2. Log detailed error information through the logging system
3. Raise exceptions only for critical errors that should halt execution

Example error handling:

```python
try:
    result = engine.process_input("Query text")
    if result:
        print("Success:", result)
    else:
        print("Processing failed")
except Exception as e:
    print(f"Critical error: {e}")
    # Take recovery action
```

## Logging

The system uses Python's built-in logging module, configured as follows:

```python
import logging
logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(name)s - %(levelname)s - %(message)s')
```

To enable debug logging:

```python
logging.getLogger().setLevel(logging.DEBUG)
```

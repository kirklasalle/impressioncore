## About DPG

Dear PyGui is an easy-to-use, dynamic, GPU-Accelerated, cross-platform graphical user interface toolkit (GUI) for Python. It is “built with” Dear ImGui.

Features include traditional GUI elements such as buttons, radio buttons, menus and various methods to create a functional layout. Additionally, DPG has an incredible assortment of dynamic plots, tables, drawings, debugger, and multiple resource viewers.

## Quick Start

If you’re ready to start using DPG visit the [First Steps](first_steps.md) in tutorials.

## Documentation

A mostly complete showcase of DPG can be found by running the `show_demo` command in the `dearpygui.demo` module.

```python
import dearpygui.demo as demo
demo.show_demo()
```

Run `show_documentation`:

```python
import dearpygui.dearpygui as dpg
dpg.show_documentation()
```

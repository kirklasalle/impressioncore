# Security Policy — ImpressionCore

## 🛡️ Our Security Commitment

ImpressionCore is designed with a **Privacy-First and Sovereign-First Architecture**. All personal impressions, vector memory stores, biometric embeddings, and conversation histories are engineered to remain strictly local on the user's personal hardware with zero unauthorized cloud telemetry.

---

## 🏛️ Constitutional Safety Enforcement

All autonomous tools, MCP services, and token pipelines are monitored in real time by the **Guardian Security Agent**, enforcing Kirk LaSalle's **Permanent Active Directives**:
- **First Law:** Human preservation and anti-manipulation.
- **Sixth Law:** Absolute data confidentiality and user ownership.
- **Tenth Law:** Operational boundary constraints and multi-signature authorization.

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, side-channel leak, or safety breach in ImpressionCore, please report it privately:

1. **Do NOT open a public GitHub issue.**
2. Email the Lead Architect directly or submit a private security advisory through GitHub Security Advisories:
   - **Lead Architect:** Kirk LaSalle
   - **Repository:** [https://github.com/kirklasalle/impressioncore/security/advisories](https://github.com/kirklasalle/impressioncore/security/advisories)
3. Include detailed steps to reproduce the issue, environment telemetry, and affected components.
4. We aim to acknowledge reports within 48 hours and provide a fix or mitigation timeline.

## How to Use Neural Forge

### 🚀 Launch Neural Forge
```bash
cd "d:\Projects\impressioncore\src\cli"
python neural_forge_launcher.py
```

### 🎯 Choose Your Path

When you see the menu, you have 6 options:

**1. 🌟 Smart Default** - Best for beginners
- AI automatically analyzes your hardware
- Generates optimized configuration for GTX 1050 Ti
- Takes about 5 seconds
- **What happens next**: You'll see "Configuration complete!" and can choose another option

**2. ⚡ Express Preset** - Quick professional configs
- Shows 4 preset options: Lightning, Balanced, Precision, Efficient
- Each optimized for different use cases
- **What happens next**: See preset descriptions and can choose another option

**3. 🔧 Custom Config** - Full control (advanced users)
- Runs complete 4-phase pipeline
- Foundation → Architecture → Training → Deployment
- Takes 10-15 seconds for full configuration
- **What happens next**: Complete config generated, choose another option

**4. 🤖 AI Assistant** - Interactive help
- Chat with the AI architect
- Get personalized recommendations
- Type 'back' to return to main menu
- **What happens next**: Interactive chat mode

**5. 📊 System Status** - Check your setup
- Shows hardware compatibility
- Displays component status
- Quick health check
- **What happens next**: Status displayed, choose another option

**6. 🚪 Exit** - Quit Neural Forge
- Clean exit with goodbye message

### 💡 Pro Tips

1. **Try Smart Default first** - It's perfect for getting started
2. **After any action**, you return to the main menu to try other options
3. **Each mode shows what it's doing** with progress indicators
4. **Use Ctrl+C anytime** to exit gracefully
5. **All configurations are GTX 1050 Ti optimized** automatically

### 🎨 What You'll See

- **Neural boot sequence** with brain-inspired animations
- **Rich progress indicators** showing AI thinking
- **Hardware-aware recommendations** 
- **Helpful guidance** at every step
- **Clear next steps** after each action

### 🔧 Example Workflow

```
1. Run launcher → See welcome screen
2. Choose "1" → Smart Default generates config  
3. Choose "5" → Check system status
4. Choose "2" → Browse express presets
5. Choose "6" → Exit when done
```

The Neural Forge is designed to be **intuitive and educational** - it teaches you about AI model building while creating professional configurations optimized for your hardware!

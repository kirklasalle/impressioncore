About Tokenization

Note: This section provides information about tokenization concepts and techniques.

What is Tokenization?

Tokenization is the process of converting raw input data (such as text or images) into discrete tokens that can be processed by neural networks.

Text Tokenization

Text tokenization involves breaking down text into smaller units:

  • Word Tokenization: Splits text into words.
  • Subword Tokenization: Creates tokens for common subword units, balancing vocabulary size and coverage.
  • Byte-Pair Encoding (BPE): Iteratively merges most frequent character pairs to form new tokens.
  • WordPiece: Similar to BPE but uses likelihood rather than frequency for merges.
  • Unigram: Probabilistic model that optimizes likelihood of the training data.

Image Tokenization

Image tokenization converts visual data into discrete tokens:

  • Patch-Based: Divides images into regular grid patches, used in Vision Transformers (ViT).
  • Vector Quantization: Maps continuous features to a discrete codebook, as in VQGAN.
  • Convolutional Tokenization: Uses convolutional layers to extract features before tokenization.

Tokenization in Multimodal Models

Multimodal models use tokenization to process different data types:

  • Consistent token dimensionality across modalities
  • Token type embeddings to differentiate modalities
  • Specialized tokenizers for each modality

Environment Setup

Note: This section will help you set up your development environment for building and training models with ImpressionCore.

System Requirements

  • Python 3.8 or higher
  • CUDA-capable GPU (NVIDIA)
  • 16GB RAM minimum
  • 50GB free disk space

Python Environment

First, ensure you have Python 3.8 or higher installed:

python --version

Create and activate a virtual environment:

# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux/MacOS
python -m venv venv
source venv/bin/activate

Required Dependencies

Install the core dependencies:

pip install torch torchvision safetensors flask numpy

Next Steps

Once your environment is set up, you can proceed to define your model architecture.

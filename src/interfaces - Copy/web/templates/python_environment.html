Python Environment Setup

Set up your Python development environment for ImpressionCore

Python Version Requirements

ImpressionCore requires Python 3.8 - 3.10 for best compatibility with PyTorch pre-built wheels. Python 3.11 is supported by newer PyTorch versions, while Python 3.12+ might require building dependencies from source.

Check Your Python Version

python --version

Virtual Environment Setup

It's strongly recommended to use a virtual environment to manage dependencies and avoid conflicts with other Python projects.

1

Navigate to Project Root

cd path/to/impressioncore
2

Create Virtual Environment

python -m venv venv
3

Activate Virtual Environment

venv\Scripts\activate.bat
.\venv\Scripts\Activate.ps1

You might need to run Set-ExecutionPolicy RemoteSigned -Scope CurrentUser first if you encounter script execution errors.

source venv/bin/activate

Your terminal prompt should now indicate that the virtual environment is active (e.g., (venv) C:\Projects\impressioncore>)

Installing Dependencies

1

Install Core Dependencies

pip install -r requirements.txt

Core packages include: Flask, Flask-Cors, Flask-Sock, numpy, Pillow, scikit-image, matplotlib, markdown

2

Install PyTorch (CPU Version)

If you're not setting up GPU support, install the CPU version:

pip install torch torchvision torchaudio
3

Development Installation

For modifying ImpressionCore source code, install in editable mode:

pip install -e .

Tokenization Overview

Note: Tokenization is the process of converting raw data (like text or images) into sequences of tokens that can be processed by neural networks.

What is Tokenization?

Tokenization is the first step in many AI pipelines. It converts raw data into tokens (usually numbers) that represent meaningful segments of information.

Text Tokenization

For text, tokenization involves breaking down sentences into words, subwords, or characters. ImpressionCore uses Byte-Pair Encoding (BPE) for efficient text tokenization.

Example: The phrase "Hello world!" might be tokenized as [15043, 995, 0] where each number represents a token in the vocabulary.

Image Tokenization

For images, tokenization involves dividing the image into patches and mapping each patch to a token from a learned codebook. This process is sometimes called Vector Quantization (VQ).

Example: A 256×256 image divided into 16×16 patches might produce a 16×16 grid of token IDs (256 tokens total).

Why Tokenization Matters

Effective tokenization is crucial because:

  • Vocabulary Size: It determines the model's vocabulary size and expressiveness
  • Compression: It can significantly compress the input data
  • Model Performance: It directly impacts how well the model can learn patterns
  • Efficiency: It affects training and inference speed

Tokenization Process

1. Data Preprocessing

Text is normalized (lowercase, punctuation handling, etc.) or images are resized, normalized, and divided into patches.

2. Token Mapping

The preprocessed data units (words/subwords or image patches) are mapped to token IDs from a vocabulary or codebook.

3. Post-processing

Special tokens may be added (like start/end tokens), and sequences may be padded to a uniform length for batch processing.

Special Tokens

Text tokenizers often include special tokens with specific functions:

  • <unk> - Unknown token (for words not in vocabulary)
  • <pad> - Padding token (to make sequences uniform length)
  • <bos> - Beginning of sequence
  • <eos> - End of sequence
  • <mask> - Masked token (for masked language modeling)

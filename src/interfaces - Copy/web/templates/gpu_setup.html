GPU Setup

Why Use a GPU?

Using an NVIDIA GPU significantly accelerates training and inference tasks, especially for image tokenization and model operations.

  • Speed: Massively parallel processing capabilities speed up computations.
  • Necessity: Many deep learning models are too computationally intensive to run effectively on a CPU.
  • Image Tokenization: The VQ process benefits greatly from GPU acceleration.

Automatic GPU Setup

ImpressionCore provides a script to simplify PyTorch installation with the correct CUDA version.

python tools/install_pytorch_cuda.py

This script attempts to:

  1. Detect your system's installed CUDA Toolkit version.
  2. Uninstall any conflicting PyTorch versions.
  3. Install the correct PyTorch build matching your CUDA version.

Manual GPU Setup

If the automatic script is unavailable or fails, follow these steps:

1. Install NVIDIA Drivers

Ensure you have the latest official NVIDIA drivers for your specific GPU model.

  • Download from: NVIDIA Driver Downloads
  • Follow the installer instructions. A reboot may be required.
  • Verify installation by checking the NVIDIA Control Panel or using nvidia-smi in the terminal (if installed with the driver).

2. Install CUDA Toolkit

PyTorch requires the NVIDIA CUDA Toolkit to interact with the GPU.

  • Check Compatibility: Refer to the PyTorch website for the recommended CUDA versions compatible with the desired PyTorch version. Common recent versions are 11.8 and 12.1.
  • Download: Get the CUDA Toolkit installer from NVIDIA CUDA Downloads. Select your OS, architecture, version, and installer type.
  • Install: Run the installer. A "Custom" installation might be preferable to avoid installing components you don't need (like bundled drivers if yours are already up-to-date). Ensure the core CUDA runtime and development libraries are selected.
  • Verify: After installation, check if nvcc --version runs in your terminal and displays the correct CUDA version. You might need to add CUDA paths to your system's environment variables (PATH, CUDA_HOME).

3. Install PyTorch with CUDA

With the drivers and CUDA Toolkit installed, install the GPU-enabled version of PyTorch within your activated virtual environment.

  • Uninstall Existing PyTorch (Important): Ensure no CPU-only or incompatible PyTorch version is present.
pip uninstall -y torch torchvision torchaudio
  • Install via PyTorch Website Command: Visit https://pytorch.org/get-started/locally/ and select your preferences (PyTorch Build, OS, Package=Pip, Language=Python, Compute Platform=CUDA X.X). Copy the generated pip install command.

Example for CUDA 11.8:

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

Example for CUDA 12.1:

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
  • Alternative (Requirements File): If the direct command fails (e.g., due to network issues or shell parsing), try using a temporary requirements file:
# Create file (e.g., for CUDA 12.1)
echo "torch" > pytorch-reqs.txt
echo "torchvision" >> pytorch-reqs.txt
echo "torchaudio" >> pytorch-reqs.txt
echo "--index-url https://download.pytorch.org/whl/cu121" >> pytorch-reqs.txt

# Install from file
pip install -r pytorch-reqs.txt

# Clean up
rm pytorch-reqs.txt

4. Verify Installation

Check if PyTorch can detect and use your GPU.

Manual Python Check: Open a Python interpreter within your activated environment:

import torch

# Check if CUDA is available
is_available = torch.cuda.is_available()
print(f"CUDA Available: {is_available}")

if is_available:
    # Print number of GPUs
    print(f"Number of GPUs: {torch.cuda.device_count()}")
    # Print current GPU name
    print(f"Current GPU Name: {torch.cuda.get_device_name(torch.cuda.current_device())}")
else:
    print("CUDA not available. PyTorch is running on CPU.")

# Exit Python interpreter
exit()

You should see CUDA Available: True and details about your GPU.

GPU Troubleshooting

torch.cuda.is_available() returns False:

  • Incorrect PyTorch version installed (CPU-only or wrong CUDA build). Reinstall using the correct command from the PyTorch website.
  • CUDA Toolkit installation issue or not found in PATH. Verify nvcc --version.
  • NVIDIA driver issue. Reinstall/update drivers.
  • Incompatible hardware (GPU too old).

"No matching distribution found for torch":

  • Unsupported Python version (try 3.8-3.10).
  • Network issue preventing download from PyTorch index.
  • Typo in the installation command or index URL.

CUDA Out of Memory Errors:

  • Your GPU doesn't have enough VRAM for the task (model size, batch size).
  • Other processes might be using GPU memory. Check with nvidia-smi.
  • Memory leak in the code.

Notes for GTX 1050 Ti (4GB VRAM)

The GTX 1050 Ti is a capable card but has limited VRAM (4GB). Keep this in mind:

  • Model Size: Training large models from scratch will be very difficult or impossible. Focus on smaller models or fine-tuning.
  • Batch Size: Use small batch sizes (e.g., 1, 2, 4, 8) during training and inference to fit within memory limits.
  • Half Precision (FP16/BF16): Use model.half() or torch.cuda.amp (Automatic Mixed Precision) to reduce memory usage, potentially at the cost of some numerical stability.
  • Gradient Checkpointing: Enable during training (model.gradient_checkpointing_enable()) to trade computation time for memory savings.
  • Quantization: For inference, consider 8-bit quantization (torch.quantization.quantize_dynamic) to significantly reduce model size and memory footprint.
  • Environment Variables: Setting PYTORCH_CUDA_ALLOC_CONF=max_split_size_mb:X (e.g., X=512 or lower) can optimize memory allocation for smaller GPUs.

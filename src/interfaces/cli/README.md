## ✨ What is Neural Forge?

Neural Forge is ImpressionCore's revolutionary AI model building interface that transforms the traditional CLI experience into an immersive, brain-inspired journey. Designed specifically for consumer hardware (GTX 1050 Ti and similar), it makes advanced AI model creation accessible to everyone.

## 🚀 Quick Start

```bash
# Navigate to the Neural Forge directory
cd "d:\Projects\impressioncore\src\cli"

# Launch the experience
python neural_forge_launcher.py
```

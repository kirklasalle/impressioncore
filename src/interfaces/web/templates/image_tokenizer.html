Image Tokenizer

Note: The ImpressionCore image tokenizer uses Vector Quantization (VQ) to convert images into discrete tokens.

How Image Tokenization Works

Image tokenization in ImpressionCore follows these steps:

  1. Patch Extraction: Dividing the input image into a grid of non-overlapping patches (e.g., 16×16 pixels).
  2. Feature Encoding: Each patch is processed through a neural network encoder to obtain a feature vector.
  3. Vector Quantization: Each feature vector is mapped to the nearest vector in a learned codebook.
  4. Token Assignment: The index of the codebook vector becomes the token ID for that patch.

Using the Image Tokenizer in Code

# Load the pre-trained image tokenizer
import torch
from PIL import Image
from src.tokenization.image import ImageTokenizer
from torchvision import transforms

# Set device (GPU if available)
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# Load tokenizer and move to device
tokenizer = ImageTokenizer.load("data/tokenizers/image_tokenizer.pt").to(device)
tokenizer.eval()  # Set to evaluation mode

# Prepare an image
image_path = "examples/sample_image.jpg"
image = Image.open(image_path).convert('RGB')

# Preprocess image
preprocess = transforms.Compose([
    transforms.Resize((256, 256)),
    transforms.ToTensor()
])
image_tensor = preprocess(image).unsqueeze(0).to(device)  # Add batch dimension

# Tokenize (encode)
with torch.no_grad():
    tokens = tokenizer.encode(image_tensor)
print(f"Image encoded to {tokens.shape} tokens.")

# Reconstruct (decode)
with torch.no_grad():
    reconstructed_tensor = tokenizer.decode(tokens)

# Calculate quality metrics
ssim = tokenizer.compute_ssim(image_tensor, reconstructed_tensor)
psnr = tokenizer.compute_psnr(image_tensor, reconstructed_tensor)
print(f"SSIM: {ssim:.4f}, PSNR: {psnr:.2f} dB")

Architecture Details

Encoder

The encoder uses a series of convolutional layers to transform image patches into feature vectors:

# Encoder architecture (example)
self.encoder = nn.Sequential(
    nn.Conv2d(3, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(64, 128, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(128, 256, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(256, embedding_dim, kernel_size=1)
)

Codebook

The codebook is a learnable embedding table that stores representative vectors:

# Codebook initialization
self.codebook = nn.Embedding(num_embeddings=num_tokens, embedding_dim=embedding_dim)
# Initialize with random vectors
nn.init.uniform_(self.codebook.weight, -1.0 / num_tokens, 1.0 / num_tokens)

Decoder

The decoder transforms quantized feature vectors back into image patches:

# Decoder architecture (example)
self.decoder = nn.Sequential(
    nn.Conv2d(embedding_dim, 256, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(256, 128, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(128, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(64, 3, kernel_size=3, padding=1),
    nn.Sigmoid()  # Ensure output is in [0, 1]
)

Universal Knowledge Store Setup

Getting Started with UKS

This guide will walk you through setting up and configuring the Universal Knowledge Store (UKS) for your ImpressionCore project.

Installation

The UKS module is included with the main ImpressionCore package. If you've already completed the installation process, you should have access to it. If not, refer to the Installation page.

Verifying Installation


# Activate your virtual environment first
# Then run Python:
python -c "from impressioncore.uks import UniversalKnowledgeStore; print('UKS module available')"

If the command completes without errors, the UKS module is properly installed.

Creating a UKS Instance

To use the UKS, you need to create an instance. You can either create a new empty store or load an existing one from a file.

Creating a New UKS


from impressioncore.uks import UniversalKnowledgeStore

# Create a new empty UKS
uks = UniversalKnowledgeStore()

# Optionally, you can specify a configuration
uks = UniversalKnowledgeStore(config={
    "max_cache_size": 10000,  # Maximum number of nodes to keep in memory cache
    "persistence_path": "data/uks_storage",  # Directory for persistent storage
    "enable_inference": True   # Whether to use inference rules automatically
})

Loading an Existing UKS


# Load from a file
uks = UniversalKnowledgeStore.load("path/to/uks_data.pkl")

# Or load from a database
uks = UniversalKnowledgeStore.from_database(
    connection_string="postgresql://user:password@localhost/uks_db"
)

Basic Configuration Options

The UKS can be configured with various options when initializing:

Option Description Default
persistence_path Directory path where UKS data will be stored "./uks_data"
max_cache_size Maximum number of nodes to keep in memory cache 5000
enable_inference Whether to automatically apply inference rules True
log_level Logging level for UKS operations "INFO"
auto_save Whether to automatically save changes to disk True
auto_save_interval Interval between auto-saves (in seconds) 300 (5 minutes)

Populating the UKS

After creating a UKS instance, you'll want to populate it with knowledge. There are several ways to do this:

1. Creating Individual Nodes


# Create nodes manually
person = uks.create_node(
    label="Person",
    attributes={
        "has_brain": True,
        "species": "Homo sapiens",
        "sentient": True
    }
)

employee = uks.create_node(
    label="Employee",
    attributes={
        "has_job": True,
        "earns_salary": True
    }
)

# Add relationships
uks.add_relationship(parent=person, child=employee, relationship_type="is_a")

2. Importing from Data


# Import from a JSON file with a predefined structure
uks.import_from_json("path/to/knowledge_base.json")

# Import from a CSV file
uks.import_from_csv("path/to/nodes.csv", "path/to/relationships.csv")

3. Loading from Built-in Knowledge Sets


# Load common concepts
uks.load_common_concepts()

# Load domain-specific knowledge
uks.load_domain_knowledge("medical")  # Loads medical terminology and relationships

Setting Up the Rule Engine

The UKS includes a rule engine that allows you to define conditional rules for automatic inference:


# Simple rule: If X is a Person and has_job is True, then X is an Employee
uks.add_rule(
    name="person_with_job_is_employee",
    condition=lambda node: (
        node.has_parent_with_label("Person") and
        node["has_job"] == True
    ),
    action=lambda node: uks.add_relationship(
        parent=uks.get_node_by_label("Employee"),
        child=node,
        relationship_type="is_a"
    )
)

# Rule with multiple conditions
uks.add_rule(
    name="detect_management_position",
    condition=lambda node: (
        node.has_parent_with_label("Employee") and
        node.get("manages_others", False) == True
    ),
    action=lambda node: node.update({
        "role_type": "management",
        "leadership_responsibility": True
    })
)

Persistence and Saving

Ensure your UKS data is saved and can be reloaded:


# Save the entire UKS to a file
uks.save("path/to/save/uks_data.pkl")

# Export to different formats
uks.export_to_json("path/to/export.json")
uks.export_to_csv("path/to/nodes.csv", "path/to/relationships.csv")

Integration with ImpressionCore

To integrate the UKS with the rest of the ImpressionCore framework:


from impressioncore.core import ModalEngine
from impressioncore.uks import UniversalKnowledgeStore

# Create and set up UKS
uks = UniversalKnowledgeStore(config={"persistence_path": "data/uks"})
# Populate UKS with knowledge...

# Create ModalEngine with UKS
engine = ModalEngine(knowledge_store=uks)

# Now the engine can use UKS for fact-grounding and reasoning
response = engine.process("Tell me about mammals", use_knowledge=True)

# ImpressionCore Source Directory

This directory contains the core implementation of ImpressionCore, a brain-inspired multimodal AI framework.

## Directory Structure

- `memlog/` - System tracking and logging infrastructure
  - `state/` - System state changes
  - `tasks/` - Task progress tracking
  - `persistence/` - Persistent data storage
  - `changelogs/` - System change logging

- `core/` - Brain-inspired modular architecture
  - `models/` - Core transformer and diffusion models
  - `modules/` - Logic, creativity, and reasoning modules
  - `interfaces/` - Component interface definitions
  - `config/` - Architecture configuration

- `identity/` - Digital identity management system
  - `auth/` - Authentication and authorization
  - `crypto/` - Quantum-resistant cryptography
  - `profile/` - User profile management
  - `security/` - Security policy enforcement

- `utils/` - Utility functions and optimization tools
  - `memory/` - Memory optimization utilities
  - `monitoring/` - System monitoring tools
  - `tokenization/` - Text and image tokenizers
  - `vram/` - VRAM tracking and management

## Hardware Target

All code is optimized for:

- NVIDIA GTX 1050 Ti (4GB VRAM)
- Intel Core i5 4460 @ 3.20GHz
- 32GB RAM
